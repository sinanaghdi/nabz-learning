# راهنمای دموی نبض یادگیری

دموی تک‌فایلی در `index.html` قرار دارد؛ CSS و JavaScript داخل همان فایل هستند، پس به build فرانت‌اند نیاز ندارد.

## امکانات نمایشی
- تغییر نقش بین مدرس و دانشجو
- داشبورد، درس‌ها، مباحث، بانک سؤال و تحلیل نمونه
- ساخت نمایشی سؤال و آزمون و انتشار پیش‌نویس
- حل آزمون نمونه و محاسبهٔ نتیجه در مرورگر

اطلاعات ساختگی هستند و در پایگاه داده ذخیره نمی‌شوند. این صفحه برای ارائهٔ محصول است، نه جایگزین نسخهٔ کامل FastAPI/Next.js.

## اجرای محلی
از ریشهٔ مخزن:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000/demo/` را باز کنید.

## انتشار
1. یک‌بار در **Settings → Pages → Build and deployment → Source** گزینهٔ **GitHub Actions** را انتخاب کنید.
2. در **Actions** گردش‌کار **Deploy interactive demo to GitHub Pages** را با شاخهٔ `main` اجرا کنید.
3. پس از موفقیت، دمو در `https://sinanaghdi.github.io/nabz-learning/` در دسترس خواهد بود.
4. تغییرات بعدی در `demo/` روی شاخهٔ `main` خودکار منتشر می‌شوند.

گردش‌کار نمی‌تواند Pages را از ابتدا فعال کند؛ این تنظیم باید یک‌بار توسط صاحب مخزن انجام شود.
